# Documentacion tecnica

## Descripcion general

Este proyecto consiste en el desarrollo de una pagina web estatica llamada **AdoptaMe**, creada utilizando HTML5 y CSS3. El objetivo del sitio es representar visualmente una plataforma de adopcion de mascotas, permitiendo registrar informacion de animales mediante un formulario interactivo.

La pagina esta compuesta por cuatro bloques principales:

- Header o barra superior de navegacion.
- Seccion de bienvenida con imagen principal.
- Formulario para registrar mascotas.
- Footer con informacion de contacto.

---

## Archivos principales

- `index.html`: contiene toda la estructura y el contenido de la pagina.
- `styles.css`: contiene todos los estilos visuales y responsive.
- `assets/`: carpeta con imagenes e iconos utilizados en el sitio.

---

## Recursos utilizados

### Imagenes

- `assets/images/Adopta_Me.png`: logo principal del sitio.
- `assets/images/portada.png`: imagen principal de mascotas.
- `assets/images/footer.png`: fondo del footer.

### Iconos

- `assets/icons/tel.svg`: icono de telefono.
- `assets/icons/mail.svg`: icono de correo.
- `assets/icons/vineta-celeste.svg`: detalle decorativo del formulario.
- `assets/icons/vineta-blanca.svg`: detalle decorativo del footer.

---

## Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

---

## Estructura del HTML

El proyecto utiliza etiquetas semanticas de HTML5 para mejorar la organizacion y accesibilidad del documento.

Etiquetas utilizadas:

- `header`
- `nav`
- `main`
- `section`
- `form`
- `footer`

---

## Organizacion del CSS

El archivo CSS esta organizado siguiendo el orden visual de la pagina:

1. Reset general.
2. Header.
3. Navegacion.
4. Main.
5. Formulario.
6. Footer.
7. Media queries responsive.

---

## Layout y responsive

La pagina utiliza Flexbox y CSS Grid para distribuir los elementos de forma ordenada. Ademas, se implementaron media queries para adaptar correctamente el diseño a celulares, tablets y computadoras.

---

## Formulario

El formulario tiene una finalidad visual y no envia datos reales a ningun servidor.

Campos utilizados:

- `input type="radio"`
- `input type="text"`
- `select`
- `input type="file"`
- `button type="submit"`

---

## Accesibilidad

Se aplicaron buenas practicas de accesibilidad mediante el uso de `label`, `for`, `id` y atributos `alt` en imagenes.
